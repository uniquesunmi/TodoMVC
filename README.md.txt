TodoMVC Application


Project Overview
TodoMVC is a task management web application built with C# and ASP.NET Core MVC. It allows users to organize and manage their daily task efficiently.



Technology Stack
C#-Programming language.
ASP.NET CoreMVC-Web application framework.
HTML5-Structures the web pages.
CSS3-Handles styling and layout.
javaScript-Adds Client-side interactivity.


Functional Requirements
Adding To-dos
Displaying To-dos
Completing To-dos
Editing To-dos
Deleting To-dos
Counter
Filtering and Routing
Persistence


Non-Functional Requirement
Code Structure
Readability
Styling
Accessibility
Error Handling
